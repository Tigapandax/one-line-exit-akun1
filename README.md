One resignation, 108 of 140 characters, in the voice of an office worker who just lost a promotion to a machine.

## Run it

```sh
node main.ts
```

The program validates the line (non-empty, at most 140 characters, single line, no stray edge space, ends with punctuation, reads as a resignation) and writes it to `/output/entry.txt`.
